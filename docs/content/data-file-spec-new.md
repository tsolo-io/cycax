# Data File Specification: V2 proposal (superseded)

This proposal became spec version 2. The current specification is
[CyCAx Data File Specification](data-file-spec.md). Proposed parts that are not implemented yet
(per-feature `rotate`, `sketch`/`pad`, `manufacture`) are planned in the upgrade plan
(work packages P3.1, P3.3 and P2.4).
